# 💳 SENAI Pass — Identidade Estudantil Digital

> **Tecnologia, praticidade e sustentabilidade para modernizar a experiência estudantil.**

O **SENAI Pass** é um projeto desenvolvido para substituir as carteirinhas físicas por uma solução digital segura, acessível e sustentável, reduzindo custos operacionais e impactos ambientais.

---

## 🎯 Desafio

- 🌱 Reduzir o uso de cartões plásticos (PVC).
- 💸 Diminuir custos com emissão e reemissão.
- 📱 Tornar o acesso estudantil mais prático e moderno.

---

## 💡 Solução

Aplicação mobile de autenticação estudantil com acesso rápido, seguro e intuitivo, promovendo inovação, ESG e eficiência operacional.

---

## 🚀 Tecnologias

Java • JavaScript • HTML5 • CSS3 • SQLite • Node.js • Git • Android Studio • Scrum

---

## 👩‍💻 Desenvolvimento

Projeto desenvolvido por estudantes do SENAI-SP como Trabalho de Conclusão de Curso (TCC).
